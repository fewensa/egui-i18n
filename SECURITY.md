# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.2.x   | Yes       |
| < 0.2   | No        |

0.2.1 is the current release. It keeps the 0.2 library API and builds the
examples against egui / eframe 0.37.

## Reporting a vulnerability

Please report security issues privately through
[GitHub Security Advisories](https://github.com/fewensa/egui-i18n/security/advisories/new).

Do not open a public GitHub issue for a vulnerability.

Include the crate version, the feature flags you enabled (`classic` or
`fluent`), and a description that lets us reproduce the problem. We will
acknowledge the report, work on a fix, and coordinate disclosure with you.
If the advisory form is unavailable, the repository owner still needs to
enable private vulnerability reporting under the repository security settings.
